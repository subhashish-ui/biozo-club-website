BIOZO Technical Club Portal - Full Stack Demo
==============================================

This package contains the frontend and backend for the BIOZO Technical Club Portal.

FILES INCLUDED:
1. biozo9.html - The interactive web portal (Frontend)
2. server.py   - The Python API server (Backend)

HOW TO RUN:
-----------
1. Start the Backend Server:
   - Open a terminal or command prompt in this folder.
   - Run the command: python server.py
   - You should see: "Starting BIOZO Python Backend running at http://localhost:3000"

2. Open the Portal:
   - Open 'biozo9.html' in any modern web browser (Chrome, Edge, Firefox).

HOW IT WORKS:
-------------
- The portal is currently set to "Live Mode." It will fetch updates and stats from the running server.py.
- Induction applications submitted through the form will be saved locally into a file named 'applications.json' in this same folder.

NOTE FOR COLLEAGUES:
--------------------
Ensure you have Python installed on your system to run the backend server. If you don't have Python, you can still view the portal's design by opening the HTML file directly, though form submissions will require the server.
